# براند أبو البنات — متجر العسل

موقع مستقل لبراند أبو البنات. يعرض منتجات العسل ومنتجات النحل والخلطات، ويقرأ الكتالوج من Google Sheets عند إعداد `VITE_HONEY_SHEET_ID`.

## تشغيل محلي

```powershell
npm ci
npm run dev
```

بدون معرّف الشيت يعرض الموقع بيانات تجريبية مبنية على المنتجات والأسعار المتاحة. المنتجات ذات السعر صفر تظهر كاستفسار ولا تدخل السلة.

## اختبار وبناء

```powershell
npm test
npm run build
```

ينشر GitHub Actions الموقع على المسار `/abu-el-banat-honey-store/`، ويضبط معرّف شيت البراند أثناء البناء. الطلبات تنتقل مباشرة إلى واتساب بعد فحص السعر والتوافر، وتُحدد رسوم التوصيل هناك. لإدارة المنتجات والصور والأقسام راجع [دليل المتجر](HONEY_STORE_SETUP_AR.md).
